# ESP32-S3 AI 智能监控终端 (ESP32-S3 AI Monitor)

基于 ESP32-S3 (N16R8) 与 OV3660 摄像头打造的高性能、低延迟局域网监控系统。

本项目采用 **“边缘推流 + 前端 AI 计算”** 架构。ESP32 仅负责视频流的采集推送与底层硬件控制，将所有的图像特效渲染与 AI 目标检测全部交由电脑浏览器（前端）处理。彻底释放了微控制器的算力，实现了极高的视频流畅度。

## ✨ 核心功能

### 1. 极低延迟的视频流推流
* 基于 HTTP MJPEG 协议单端口推流，画面稳如泰山。
* 网页端支持动态切换分辨率（VGA / SVGA / XGA）。
* 网页端支持动态调节画质、亮度、对比度，并永久保存至 ESP32 闪存 (NVS)。

### 2. 纯前端视觉特效 (零硬件负担)
* 利用 CSS Filters 实现反色(X光)、黑白、高对比度等滤镜。
* 点击秒生效，完全不消耗 ESP32 性能。

### 3. 本地化记录 (不依赖 SD 卡)
* **截图下载**：利用 Canvas 截取当前画面，直接保存 JPG 到本地。
* **视频录像**：利用浏览器 `MediaRecorder` API 录制视频流，直接下载 WebM 视频文件至电脑。

### 4. 前端 AI 智能识别
* 内置 TensorFlow.js 与 COCO-SSD 模型（使用国内镜像源加速加载）。
* 实时检测画面中的人、手机等目标，并统计画面人数。
* 数据无需上传云端，完全利用电脑本地 CPU/GPU 进行离线推理，保护隐私。

### 5. 断电记忆与双模配网
* 网页端一键修改 WiFi 热点名称与密码。
* 支持 STA 模式连接家庭路由器，实现局域网跨设备访问。

## 🛠️ 硬件要求
* **主控板**：ESP32-S3（必须带有 **8MB PSRAM** 和 **16MB Flash**，如 N16R8 模块）。
* **摄像头**：OV2640 / OV3660 (DVP 接口)。
* **供电**：5V 2A 充电头或充电宝（运行 WiFi 推流时功耗较高，电脑前置 USB 供电不足会导致重启）。

## ⚙️ 开发环境配置 (Arduino / Mind+)

1. **开发板选择**：`ESP32S3 Dev Module`
2. **Flash Size**：`16MB`
3. **PSRAM**：必须开启 `OPI PSRAM`（非常关键，否则内存溢出）。
4. **Partition Scheme**：`Huge APP (3MB No OTA/1MB SPIFFS)`

## 🚀 快速开始

1. 使用上述环境将源码烧录进 ESP32-S3。
2. 设备启动后，用电脑或手机搜索 WiFi 热点：`ESP32-Cam`，默认密码 `12345678`。
3. 连接成功后，在浏览器地址栏输入：`http://192.168.4.1` 进入控制台。
4. 点击“启动 AI 识别”即可体验（首次运行需保持电脑有外网以下载 AI 模型）。

## 🧠 工程排雷记录

在开发过程中踩过并解决的核心坑点，供后来的开发者参考：

* **供电崩溃 (Brownout)**：ESP32-S3 开启摄像头推流瞬间电流激增，极易引起电压跌落。务必使用独立电源，或在 3.3V 处并联 100μF 电容。
* **网页卡死 (TCP Blocking)**：MJPEG 长连接容易阻塞 WebServer。通过加入 `yield()` 并严格管理单端口连接，解决了通信阻塞问题。
* **AI 库访问受限**：由于国内网络环境，原生 jsdelivr CDN 常常超时。代码已替换为 `jsdmirror` 国内镜像，极大提升了 AI 加载成功率。
